🔐 Konfigurasi Meta Graph API

Dapatkan dari Meta Graph API Explorer. Permission yang dibutuhkan: instagram_basic, instagram_content_publish

Cek di: Instagram → Settings → Professional account → Instagram ID

📖 Cara Setup Meta API (Step by step)
  1. Buka developers.facebook.com → Buat App baru
  2. Pilih tipe app: Business
  3. Tambahkan produk Instagram Graph API
  4. Di menu Roles → Add Instagram Tester → accept di akun Instagram kamu
  5. Buka Graph API Explorer → pilih app kamu
  6. Tambahkan permission: instagram_basic, instagram_content_publish, pages_read_engagement
  7. Klik Generate Access Token → salin tokennya
  8. Jalankan query: GET /me/accounts untuk dapat page ID
  9. Lalu: GET /{page-id}?fields=instagram_business_account untuk dapat Instagram Account ID
  10. Masukkan token dan ID ke form di atas → klik Simpan
⚠️ Syarat akun Instagram
  • Akun harus tipe Business atau Creator (bukan personal)
  • Akun harus terhubung dengan Facebook Page
  • Gambar harus berformat JPEG, rasio antara 4:5 sampai 1.91:1
  • URL gambar harus HTTPS dan bisa diakses publik
  • Token perlu diperbarui setiap 60 hari (atau gunakan long-lived token)
